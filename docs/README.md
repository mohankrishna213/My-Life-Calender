# Focus website

Minimal static marketing site and privacy policy for **Focus: Goal & Habit Tracker**.

## GitHub Pages

In the repository settings, open **Pages** and configure:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/docs`

The site will be available at:

`https://mohankrishna213.github.io/My-Life-Calender/`

Privacy policy:

`https://mohankrishna213.github.io/My-Life-Calender/privacy-policy.html`

The site has no build step and contains only HTML, CSS, JavaScript, and a small SVG icon.
