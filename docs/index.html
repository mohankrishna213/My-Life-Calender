THE IDEA

Small actions.
Long horizons.

Focus keeps the daily work lightweight and lets the bigger picture emerge naturally.

01

Choose a goal

Set one goal, give it a start and end date, and let the calendar define the journey.

02

Do the daily work

Create tasks for a day, repeat them when useful, and break larger tasks into subtasks.

03

See the streak of effort

Each day changes intensity based on completion, creating a quiet visual record of consistency.

YOUR CALENDAR

A year, one day at a time.

The main view is a contribution-style grid. Empty days stay neutral. As work gets done, days become more visible—from getting started to all done.

PRIVACY

Built around local data.

Focus currently has no account system and no backend service. Goal and task data is kept on the device; optional reminders use Android notifications, and the optional lock-screen feature writes the generated image through Android’s wallpaper APIs.
